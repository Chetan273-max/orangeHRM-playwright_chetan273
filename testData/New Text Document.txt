to find web element on the basis of id,class,name,attribute & other attribute...
if inbuilt fails go to css

2 ways to find CSS:

a> relative css selectors/Locators
b> Absulute css selectors/Locators

a>relative css selectors/Locators:-
it finds exact element directly without finding from root

a> id attribute  :- use # // div#idvalue
b> class attribute:- use . / single value/multiple value:- space not allowed , use . to join to class name
c> other/any attribute:- use tag[attributeName = 'value']
d> class and any attribute:- .classvalue[attributeName = 'value']
